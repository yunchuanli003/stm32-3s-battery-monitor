## 四、维护约定

- 新增素材按 `项目一_<版本>_<用途>.<扩展名>` 命名，版本号与 `CHANGELOG.md` 对齐
- 不改写原始像素与码流；需要小图时在引用处用 HTML `width` 属性控制显示尺寸，不生成第二份文件
- 被取代的素材移入 `_历史_<版本>/`，不删除
- 图片与视频按二进制入库（见 `.gitattributes`），不参与文本 diff
