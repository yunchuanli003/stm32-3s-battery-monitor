## 版本沿革

以下仅作技术演进说明，1.0 与 2.0 的**完整快照（代码、图纸）不在本仓库内**；仓库里唯一与 2.0 有关的是 3 件演示素材（实物图 / 串口截屏 / 演示视频），放在 `项目一_3.0/05_交付产物/演示素材/_历史_2.0/`，供 3.0 的历史文档取证，不是可运行的旧版本。

```
1.0  面包板原型，验证「能测电压、能报警」
  ↓
2.0  面包板完整版，补齐电机风扇、按键启停、OLED 显示、DMA 采集
  ↓
3.0  打板成型，引脚重排到 PCB、NTC 改 B 值法、OLED 中文化、刷新与按键时序重做
```

从 10 月起的固件迭代（v2.1.0 → v3.0.7）全部记录在 [`项目一_3.0/CHANGELOG.md`](项目一_3.0/CHANGELOG.md)，项目入口文档见 [`项目一_3.0/README.md`](项目一_3.0/README.md)。

## 开发时间线

| 时间 | 节点 | 关键动作与结果 |
|---|---|---|
| 2026-06-01 | 1.0.0 面包板原型 | 跑通「分压采样 → ADC → 过压/欠压判断 → 蜂鸣器报警」最小闭环 |
| 2026-06-04 | 2.0.0 面包板完整版 | 补上 TB6612 驱动风扇、按键启停、OLED 显示、DMA 采样 |
| 2026-10-21 | 引脚定义定稿 | 从核心板原理图逐脚提取 40 个引脚，与 EDA 网表比对 40/40 一致、0 错误，作为 PCB 布线的唯一依据 |
| 2026-10-23 | 2.1.0 PCB 版固件迁移 | 打样下单后把引脚从面包板配置迁到 PCB 版；NTC 温度由查表改 B 值公式 |
| 2026-10-31 | 焊接 | 按「位号 + 引脚清单」逐点核对后上电，避免错焊返工 |
| 2026-11-14 | 3.0.0 中文界面 + 双向心跳 | 38 字中文点阵、4 行布局；ESP8266 回 `PONG`，屏上「无线通/无线发」成为可被证伪的真状态 |
| 2026-11-14 | 3.0.1 按键时序重做 | 根因是拿「循环圈数」当时间基准，实测一圈 94 ms 而非设计假设的 50 ms，所有时长被放大 1.9 倍；改 `HAL_GetTick()` 毫秒制后消除 6.5 s 迟滞 |
| 2026-11-14 | 3.0.2 消除 OLED 闪烁 | 根因是每帧把整屏写黑一遍；改为显存双缓冲 + 差异刷新，稳态发送 0 字节、刷新耗时 47 ms → 0.8 ms |
| 2026-11-14 | 3.0.3 蜂鸣器非阻塞 | 报警原先把主循环卡死 280 ms；改为节拍表 + `Beep_Task()` 轮询，阻塞 0 ms |
| 2026-11-14 | 3.0.4 整机竣工 | 打样、焊接、整机实测完成，四件演示素材归档入库 |
| 2026-11-14 | 3.0.5 ~ 3.0.7 归档 | 版本命名统一、目录收敛、重复副本清零，全项目链接 0 断链 |

**三个值得记录的真实排查**（都写在 CHANGELOG 的对应条目里，没有事后美化）：

1. **OLED 每秒黑闪**：第一版把刷新率从 1 Hz 提到 10 Hz，结果黑闪变成持续抖动——方向本身错了。真正的因是每帧无条件整屏写黑，改成「显存 + 差异刷新」后才归零。
2. **按键要按住 6.5 秒才响应**：状态机用循环圈数折算时间，而主循环一圈是 50 ms 延时加约 44 ms 刷屏，实际 94 ms。时间基准换成毫秒后，消抖窗口也从 500 ms 修正到 30 ms。
3. **风扇不转**：不是电机坏，是 20 kHz 斩波让 4010 无刷风扇内部驱动 IC 欠压复位；换成 12 V 有刷电机后，40% / 70% 两档实测 4.7 V / 8.0 V 均正常起转。

## 关于未发布的 1.0 / 2.0

2026-11-14 起，这两个版本从公开仓库移除，原因有两条：

1. **1.0 的汇报 PPT 由第三方商业模板二次修改**，模板授权条款不支持公开再分发，继续公开存在侵权风险；
2. **2.0 的内容已被 3.0 完整覆盖**，保留在公开仓库里只增加体积，不增加信息量。

3.0 内部仍保留了对照所需的历史素材（`项目一_3.0/05_交付产物/演示素材/_历史_2.0/`），因此正文不会裂图。如确需查阅 1.0 / 2.0 的完整快照，请联系作者。
