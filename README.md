## 版本沿革

以下仅作技术演进说明，1.0 与 2.0 的代码、图纸与素材**不在本仓库内**。

```
1.0  面包板原型，验证「能测电压、能报警」
  ↓
2.0  面包板完整版，补齐电机风扇、按键启停、OLED 显示、DMA 采集
  ↓
3.0  打板成型，引脚重排到 PCB、NTC 改 B 值法、OLED 中文化、刷新与按键时序重做
```

从 10 月起的固件迭代（v2.1.0 → v3.0.7）全部记录在 [`项目一_3.0/CHANGELOG.md`](项目一_3.0/CHANGELOG.md)，项目入口文档见 [`项目一_3.0/README.md`](项目一_3.0/README.md)。

## 关于未发布的 1.0 / 2.0

2026-11-14 起，这两个版本从公开仓库移除，原因有两条：

1. **1.0 的汇报 PPT 由第三方商业模板二次修改**，模板授权条款不支持公开再分发，继续公开存在侵权风险；
2. **2.0 的内容已被 3.0 完整覆盖**，保留在公开仓库里只增加体积，不增加信息量。

3.0 内部仍保留了对照所需的历史素材（`项目一_3.0/05_交付产物/演示素材/_历史_2.0/`），因此正文不会裂图。如确需查阅 1.0 / 2.0 的完整快照，请联系作者。

## 版本号约定

- **项目版本**（目录命名）：`项目一 1.0 / 2.0 / 3.0`，只在形成可交付快照时进位
- **固件版本**（CHANGELOG 内）：`v3.0.x` 这类三段号，记录每次代码改动
- 2026-11-14 起两者对齐：项目一 3.0 对应固件 v3.0.0 ~ v3.0.7；此前的 1.0.0 / 2.0.0 / 2.1.0 保留原编号
