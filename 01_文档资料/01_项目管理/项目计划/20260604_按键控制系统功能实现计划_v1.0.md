# 按键控制系统功能实现计划

## 项目背景

当前项目已实现三串锂电池电压监测功能，包括：
- ADC电压采集（PA0单通道）
- 过压欠压报警（LED + 蜂鸣器）
- 串口数据打印（115200波特率）

需要增加按键控制功能，实现系统的开启和停止控制。

## 需求分析

### 功能需求
1. KEY1按键按下：系统开启，恢复电压监测
2. KEY2按键按下：系统停止，暂停电压监测
3. 按键操作后，串口发送反馈信息
4. 系统停止时，关闭LED和蜂鸣器

### 硬件资源
- KEY1按键：PA0（与ADC冲突，需要调整）
- KEY2按键：PC13

## 问题与挑战

### 引脚冲突问题
- PA0同时被ADC和KEY1使用，导致冲突
- 需要解决引脚复用问题

### 解决方案选项

| 方案 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| **方案A** | 只用KEY2单键控制，短按停止，长按开启 | 无需改硬件 | 操作稍复杂 |
| **方案B** | KEY2做切换开关，按一下开启，再按一下停止 | 操作简单 | 用户需要记住当前状态 |
| **方案C** | 将ADC移到PA1，KEY1用PA0 | 两个按键都能用 | 需要改硬件接线 |

## 推荐方案

**方案A：单键控制（KEY2）**

理由：
- 无需修改硬件接线
- 功能完整
- 用户学习成本低

## 功能设计

### 按键定义
- **短按KEY2**（<3秒）：系统停止
- **长按KEY2**（≥3秒）：系统开启

### 系统状态控制
```c
uint8_t system_running = 1;  // 1=运行, 0=停止
```

### 串口反馈
- 系统开启：打印"[系统] 系统已经开启"
- 系统停止：打印"[系统] 系统已经停止"

### 停止模式行为
1. 停止ADC电压采集
2. 关闭LED报警灯
3. 关闭蜂鸣器
4. 暂停串口电压数据打印

## 实现步骤

### 步骤1：GPIO配置
1. 配置KEY2（PC13）为输入模式
2. 配置上下拉电阻（根据硬件实际情况）

### 步骤2：按键扫描函数
```c
void Key_Scan(void) {
    // 按键消抖
    // 长按计数
    // 短按/长按判定
}
```

### 步骤3：系统状态控制
1. 添加 system_running 变量
2. 在主循环中根据状态控制功能

### 步骤4：串口反馈
1. 按键触发后发送状态信息
2. 确保信息发送完成再改变状态

## 风险评估

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 按键误触发 | 系统意外启停 | 增加软件消抖 |
| 串口信息延迟 | 用户看不到反馈 | printf后加延时 |
| 长按时间不合适 | 用户体验差 | 可调参数，默认3秒 |

## 测试验证

### 测试用例
1. 上电默认状态：系统运行
2. 短按KEY2：系统停止，串口打印
3. 长按KEY2 3秒：系统开启，串口打印
4. 系统停止时：无电压数据输出，LED/蜂鸣器关闭
5. 系统运行时：正常电压监测和报警

## 注意事项

1. 按键消抖时间建议：20ms
2. 长按判定时间建议：3秒
3. 串口打印后加50ms延时，确保信息发送完成
4. 系统停止时，必须关闭所有输出设备
