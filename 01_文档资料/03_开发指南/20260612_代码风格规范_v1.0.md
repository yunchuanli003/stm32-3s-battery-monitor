# C 代码风格规范

## 1. 文件命名规范

### 1.1 源文件和头文件
- 使用小写字母和下划线组合
- 头文件使用 `.h` 后缀
- 源文件使用 `.c` 后缀
- 同一模块的头文件和源文件同名

**示例：**
```
motor.c
motor.h
oled.c
oled.h
```

### 1.2 头文件保护
使用 `#ifndef` / `#define` / `#endif` 格式：

```c
#ifndef __MOTOR_H
#define __MOTOR_H

/* 代码内容 */

#endif /* __MOTOR_H */
```

---

## 2. 变量命名规范

### 2.1 全局变量
- 前缀 `g_` + 模块名 + 变量名
- 使用小驼峰命名法

**示例：**
```c
uint8_t g_motorSpeed;      /* 电机速度 */
bool g_motorRunning;       /* 电机运行状态 */
```

### 2.2 局部变量
- 使用小驼峰命名法
- 变量名应具有描述性

**示例：**
```c
uint8_t speedValue;
uint32_t startTime;
```

### 2.3 宏定义
- 全大写字母，下划线分隔
- 模块名作为前缀

**示例：**
```c
#define MOTOR_MAX_SPEED    100
#define MOTOR_MIN_SPEED    0
#define OLED_I2C_ADDR      0x78
```

---

## 3. 函数命名规范

- 前缀：模块名 + `_`
- 使用小驼峰命名法
- 函数名应清晰表达功能

**示例：**
```c
void Motor_Init(void);
void Motor_SetSpeed(uint8_t speed);
void Motor_Start(void);
void Motor_Stop(void);
```

---

## 4. 注释规范

### 4.1 文件头注释
每个文件开头添加以下注释：

```c
/**
  ******************************************************************************
  * @file    motor.c
  * @brief   电机驱动模块
  * @author  LYC
  * @date    2026-06-04
  * @version v2.0
  ******************************************************************************
  */
```

### 4.2 函数注释
每个函数前添加注释：

```c
/**
  * @brief  电机初始化
  * @param  无
  * @retval 无
  */
void Motor_Init(void)
{
    /* 函数实现 */
}
```

### 4.3 行内注释
- 使用 `/* 注释 */` 格式
- 注释应说明"为什么"而不是"是什么"

**示例：**
```c
/* 延时2ms等待电机启动 */
HAL_Delay(2);
```

## 5. 代码格式规范

### 5.1 缩进
- 使用4个空格缩进
- 不使用Tab字符

### 5.2 大括号
- 大括号独占一行
- 代码块内缩进4空格

**示例：**
```c
if (condition)
{
    /* 代码 */
}
else
{
    /* 代码 */
}
```

### 5.3 空格
- 运算符前后加空格
- 逗号后加空格

**示例：**
```c
a = b + c;
func(a, b, c);
```

### 5.4 行宽
- 每行不超过120字符
- 长表达式应换行

## 6. 代码结构规范

### 6.1 头文件结构
```c
/* 头文件保护 */
#ifndef __XXX_H
#define __XXX_H

/* 包含头文件 */
#include "stm32f1xx_hal.h"

/* 宏定义 */
#define XXX_XXX    0

/* 类型定义 */
typedef struct {
    /* 结构体成员 */
} XXX_TypeDef;

/* 函数声明 */
void XXX_Init(void);

#endif /* __XXX_H */
```

### 6.2 源文件结构
```c
/* 文件头注释 */

/* 包含头文件 */
#include "xxx.h"

/* 全局变量定义 */

/* 局部变量定义 */

/* 函数实现 */
```

## 7. 错误处理规范

- 函数返回值使用 `HAL_StatusTypeDef`
- 重要操作必须检查返回值

**示例：**
```c
HAL_StatusTypeDef status;
status = HAL_UART_Transmit(&huart1, data, len, 100);
if (status != HAL_OK)
{
    /* 错误处理 */
    Error_Handler();
}
```

---

## 8. 其他规范

### 8.1 魔法数字
- 不直接使用数字常量
- 使用宏定义或枚举

**错误示例：**
```c
for (i = 0; i < 100; i++)  /* 100是什么？ */
```

**正确示例：**
```c
#define BUFFER_SIZE    100
for (i = 0; i < BUFFER_SIZE; i++)
```

### 8.2 函数长度
- 单个函数不超过50行
- 复杂功能拆分为多个子函数

### 8.3 未使用变量
- 及时删除未使用的变量
- 若有意保留，添加注释说明

---

## 9. 编译零告警原则

- 代码编译必须做到0错误0告警
- 常见告警及处理方式：

| 告警类型 | 处理方式 |
|---------|---------|
| 未使用变量 | 删除变量或添加注释说明用途 |
| 隐式类型转换 | 显式强制类型转换 |
| 函数未声明 | 添加函数声明或包含头文件 |
