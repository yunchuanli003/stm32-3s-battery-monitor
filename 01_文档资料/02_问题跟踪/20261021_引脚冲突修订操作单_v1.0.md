# 引脚修订操作单

> 背景：野火小智核心板板载 PA0=KEY1、PA1=LED_R、PA2=LED_G、PA3=LED_B（官方引脚表与实物照片双重确认）
> 目标：把 ADC 与电机控制挪到空闲脚，其余不动
> 适用工程：`02_固件代码/STM32F103C8T6/LYC1`
> **状态：代码已改完，不需要打开 CubeMX**

## 二、已完成的改动（3 个文件，9 处）

| 文件 | 改了什么 |
|---|---|
| `Core/Src/adc.c` | 通道 `ADC_CHANNEL_0`→`ADC_CHANNEL_4`、`ADC_CHANNEL_1`→`ADC_CHANNEL_5`；MspInit 里模拟脚从 `GPIO_PIN_0\|GPIO_PIN_1` 改为 `GPIO_PIN_4\|GPIO_PIN_5`；DeInit 同步 |
| `Core/Inc/motor.h` | `MOTOR_AIN1/AIN2/STBY` 的引脚号改为 `GPIO_PIN_12/13/14`，端口改为 `GPIOB` |
| `Core/Src/motor.c` | 时钟 `__HAL_RCC_GPIOA_CLK_ENABLE()` 改 `GPIOB`；`HAL_GPIO_Init` 的端口参数改 `GPIOB` |

`main.c` 一行没动：`adc_dma_buf[0]` 仍是电压、`[1]` 仍是温度（扫描顺序没变）。

### 为什么没走 CubeMX

**因为这个工程的 `LYC1.ioc` 早就和代码不同步了。**

ioc 里只有一路 ADC（`ADC_CHANNEL_0`，`NbrOfConversionFlag=1`），而代码里实际配置了 `CHANNEL_0` + `CHANNEL_1` 两路。用人话说：有人之前直接在代码里加了温度通道，没回头改 ioc。

所以现在打开 CubeMX 点"生成代码"，它会按 ioc 的旧配置把温度通道**删掉**——不是修好，是弄坏。

**结论：以代码为准，不要用 CubeMX 重新生成这个工程。**

如果以后确实要动别的外设，顺序是：先在 CubeMX 里把 ADC 两通道（CH4/CH5）和 PA4/PA5 手动补齐 → 确认引脚的 `Reset_State` 都对了 → 再生成。

保险起见，可以把 `LYC1.ioc` 改名成 `LYC1.ioc.bak`，避免手滑点开就用。

## 三、改完后确认 3 处

**1. `Core/Inc/motor.h`**

```c
#define MOTOR_AIN1_PIN    GPIO_PIN_12
#define MOTOR_AIN1_PORT   GPIOB
#define MOTOR_AIN2_PIN    GPIO_PIN_13
#define MOTOR_AIN2_PORT   GPIOB
#define MOTOR_STBY_PIN    GPIO_PIN_14
#define MOTOR_STBY_PORT   GPIOB
```

**2. `Core/Src/adc.c`**

```c
sConfig.Channel = ADC_CHANNEL_4;   // Rank1，PA4，电池电压
sConfig.Channel = ADC_CHANNEL_5;   // Rank2，PA5，温度
```

**3. `Core/Src/main.c`**

```c
uint16_t adc_volt = adc_dma_buf[0];   // 不变
uint16_t adc_temp = adc_dma_buf[1];   // 不变
```

## 四、验证（有电源时做）

| 步骤 | 期望现象 |
|---|---|
| 上电，串口看 `Battery:` | 读数与实际电池电压接近（先不管误差，等重新标定） |
| 按住板载 **KEY1** | **电压读数不再变化**（改对了的铁证） |
| 电机正转 | 板载 RGB 灯**不再跟着亮**（PA1~PA3 已空出） |
| 电机反转 / 停止 | 同上，灯无反应 |
| 按 KEY2（板载或外接） | OLED 的 `Sys:` 状态切换 |

**注意**：KEY1 现在仍接在 PA0 上，但 PA0 已不再被 ADC 使用，按它没有任何影响。

## 五、改完还要做的一件事

`divider_k = 6.21f` 是在 PA0 被 KEY1 并联的状态下标定出来的。换到 PA4 后分压网络变干净了，**需要重新标定**：

```
新系数 = 6.21 × (万用表实测电压 ÷ 串口显示电压)
```

温度和原来一样：接上 NTC，串口值与温度计对比，按比例修正（LED 不再挂在这两个脚上，读数会比以前稳）。
