## 问题记录

### 问题1: 电机无法转动

#### 问题描述
- **现象**: 代码配置正确，GPIO和PWM输出正常，但电机始终无法转动
- **排查过程**:
  1. 检查代码中GPIO配置（PA2, PA3, PA6）- 正常
  2. 检查TIM3 PWM配置 - 正常
  3. 检查TB6612接线 - 接线正确
  4. 测量电机驱动引脚电压 - 发现异常

#### 根本原因
**江科大套件中的面包板电源轨是分段的，左右两侧不连通**，导致：
- STM32开发板的GND与电机驱动模块的GND不共地
- 电机驱动模块电源与STM32之间存在电位差
- 控制信号无法正确识别

#### 解决方案
**连接面包板的电源轨，让所有部件共地**：
1. 用杜邦线连接面包板左侧和右侧的GND轨
2. 用杜邦线连接面包板左侧和右侧的VCC轨
3. 确保STM32、TB6612、电机电源共地

#### 验证结果
- ✅ 共地后电机正常转动
- ✅ GPIO测试模式正常工作
- ✅ PWM调速功能正常

### 更正后的正确接线

| STM32引脚 | TB6612引脚 | 面包板 | 备注 |
|-----------|------------|--------|------|
| PA2       | BIN1       | -      | 电机方向控制 |
| PA3       | BIN2       | -      | 电机方向控制 |
| PA6       | PWMB       | -      | PWM调速 (TIM3_CH1) |
| GND       | GND        | GND 轨 | 共地！重要！ |
| 5V        | VCC        | VCC 轨 | 逻辑电源 |
| -         | STBY       | 3.3V   | 使能芯片 |
| -         | VM         | 外部电源 | 电机电源(12V) |

> **重要提示**: 面包板两侧电源轨必须用杜邦线连通！

---

## 经验总结

1. **共地问题是嵌入式调试的首要检查点**
2. **面包板电源轨分段是常见陷阱**，务必用万用表确认
3. **多模块系统必须确保所有模块GND连接在一起**
4. **调试时先检查硬件连接，再检查软件配置**

### 问题2: 温度模拟模式下风扇/电机不工作

#### 问题描述
- **现象**: 温度模拟模式下风扇不转，正常温控逻辑也有问题

#### 根本原因（修正版）
**低级错误**: 误以为风扇和电机是两个独立设备，实际上：**
- **130直流电机转轴上插着风扇！
- **电机转 = 风扇转！
- **控制电机PWM = 控制风扇转速！

之前错误地把风扇和电机分成两个PWM通道，导致逻辑混乱。

#### 解决方案
**统一控制逻辑：电机即风扇：**
1. **删除独立风扇PWM控制（TIM3_CH2）
2. **所有风扇控制改用 `Motor_Forward(speed)` - 设置电机速度=风扇速度
3. **停止风扇 = `Motor_Stop()` - 停止电机=停止风扇
4. **初始化只需要 `Motor_Init()` 即可

---

### 问题3: 电机从未初始化导致不工作

#### 问题描述
- **现象**: 代码编译正常但电机/风扇不转
- **原因**: `Motor_Init()` 从未在 main.c 中被调用！
- **解决**: 在初始化阶段调用 `Motor_Init()` 和 `Motor_Enable()`
