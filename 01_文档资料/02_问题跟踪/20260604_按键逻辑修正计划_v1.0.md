# 按键逻辑修正计划

## 问题分析

用户需求与当前实现不符：

| 操作 | 当前实现 | 用户需求 |
|------|----------|----------|
| **短按KEY2** | 系统停止 | 系统开启 |
| **长按KEY2** | 系统开启 | 系统停止 |

用户明确说："key2按键长按、串口打印系统停止的信息后，系统才停止"

## 修复方案

将长按和短按的功能对调：
- **短按KEY2**：系统开启
- **长按KEY2**：系统停止（3秒）

## 修改内容

**文件：** `02_固件代码/STM32F103C8T6/LYC1/Core/Src/main.c`

### 长按触发逻辑（当前）
```c
// 长按触发：系统开启
if(system_running == 0)
{
  printf("\r\n[系统] 系统已经开启\r\n");
  HAL_Delay(50);
  system_running = 1;
  ...
}
```

### 长按触发逻辑（修正后）
```c
// 长按触发：系统停止
if(system_running == 1)
{
  printf("\r\n[系统] 系统已经停止\r\n");
  HAL_Delay(50);
  system_running = 0;
  ...
}
```

### 短按触发逻辑（当前）
```c
// 短按触发：系统停止
if(system_running == 1)
{
  printf("\r\n[系统] 系统已经停止\r\n");
  HAL_Delay(50);
  system_running = 0;
  ...
}
```

### 短按触发逻辑（修正后）
```c
// 短按触发：系统开启
if(system_running == 0)
{
  printf("\r\n[系统] 系统已经开启\r\n");
  HAL_Delay(50);
  system_running = 1;
  ...
}
```

## 验证方法

1. 烧录修改后的代码
2. **长按KEY2 3秒**：串口显示"系统已经停止"，监测停止
3. **短按KEY2**：串口显示"系统已经开启"，恢复监测
