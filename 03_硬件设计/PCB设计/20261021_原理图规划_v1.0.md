# 原理图规划（立创EDA）

> 对应设计输入：`20261021_PCB打样设计输入_v1.0.md`
> 目标：一次画对，避免"板子回来才发现接错"

---

## 一、分页方案（4 页）

按功能分页，每页只做一件事。页数不是越多越好，4 页是这块板的甜点区。

| 页 | 名称 | 放什么（位号） |
|---|---|---|
| Sheet 1 | 电源与保护 | J1、F1、D1、C1、M2（Buck 模块座）、C3、U3、C12、C13 |
| Sheet 2 | 模拟采样 | R1、R2、R3、RN1、C11×2 |
| Sheet 3 | 输出与交互 | M1（TB6612 座）、C2、D2、J2、R5、LED1、R6、Q1、BUZ1、R4、SW1、C4 |
| Sheet 4 | 主控与接口 | U1（核心板座 2×20）、J3（OLED）、J4（SWD）、J5（串口）、J6（WiFi） |

**为什么把主控放最后**：U1 有 40 个引脚，先画它等于面对一堵墙；把电源、模拟、输出画完，网络名都定好了，最后画主控就是把已有网络"对号入座"，不容易漏。

---

## 二、全局网络命名（画之前先定死）

网络名一旦定好，四条 Sheet 之间靠它连接，不用拉长线。**全部大写，带下划线**。

| 网络名 | 含义 | 出现在 |
|---|---|---|
| `VBAT` | 电池正极（保险丝前） | Sheet1 |
| `VBAT_F` | 保险丝 + 防反接之后的正极 | Sheet1、Sheet3 |
| `GND` | 公共地 | 全部 |
| `+5V` | Buck 输出 | Sheet1、Sheet2、Sheet3 |
| `+3V3` | 核心板 3.3 V 输出（给模拟与数字用小电流负载） | Sheet2、Sheet4 |
| `+3V3_WIFI` | U3 独立输出，只给 J6 | Sheet1、Sheet4 |
| `VBAT_ADC` | 分压上臂入口 | Sheet1→Sheet2 |
| `PA4` / `PA5` | ADC 输入（原 PA0/PA1，已因板载冲突改） | Sheet2→Sheet4 |
| `PB12` / `PB13` / `PA6` / `PB14` | 电机控制（原 PA2/PA3/PA8） | Sheet3→Sheet4 |
| `PB0` / `PB1` | 蜂鸣器 / LED | Sheet3→Sheet4 |
| `PB6` / `PB7` | I2C | Sheet4、J3 |
| `PA9` / `PA10` | USART1 | Sheet4、J5 |
| `USART3_TX` / `USART3_RX` | PB10 / PB11 | Sheet4、J6 |
| `WIFI_EN` / `WIFI_IO0` | 模块使能与烧录选择 | Sheet1、Sheet4 |
| `PC13` | 按键 | Sheet3→Sheet4 |

**命名两条规矩**：

1. 电源网络用 `+5V` `+3V3` 这种带正号的形式，GND 单独一种符号，不要出现 `VCC`、`VDD`、`5V` 混用
2. 信号名跟 MCU 引脚名对齐（`PA4` 而不是 `ADC1_IN0`），调试时一眼能对上数据手册

## 三、逐页画法与自检点

### Sheet 1 电源与保护

**画法顺序**：J1 → F1 → D1 → 分两路（Buck / TB6612 VM）→ 补 C1、C3 → 加 U3 及其电容

| 检查项 | 正确做法 | 常见错法 |
|---|---|---|
| 保险丝位置 | 在 D1 **之前**，紧贴 J1 | 放到 D1 之后，短路时保护不了反接二极管 |
| D1 方向 | 阳极接 VBAT，阴极出 VBAT_F | 反了整板不上电 |
| C1 位置 | Buck 输入端，靠近模块 IN+ | 画在 D1 之前，起不到抑制输入纹波的作用 |
| U3 输入 | 从 `+5V` 取电 | 从 `VBAT_F` 取电 → 压差 9 V，白烧 0.6 W |
| U3 输出 | `+3V3_WIFI` 独立命名 | 与 `+3V3` 混成一个网络 → WiFi 发射时拉垮 MCU |

**这页画完**：ERC 应无错，`VBAT_F`、`+5V`、`+3V3_WIFI` 三个网络各有明确的源。

### Sheet 2 模拟采样

**画法顺序**：R1 → R2 → 加 C11 → 引 `PA4` → R3 → RN1 → 加 C11 → 引 `PA5`

| 检查项 | 正确做法 |
|---|---|
| NTC 位置 | **下臂**（RN1 到 GND，R3 到 +3V3），与现有固件公式方向一致 |
| 电容位置 | C11 并联在 R2 / RN1 两端，即"采样点对地" |
| 采样点来源 | `PA4` `PA5` 直接从两个电阻中间引出，不要从电容另一端引 |
| 封装 | R1/R2/R3 用 0805；RN1 是直插 NTC，别错用贴片 |

> 这一页只有 5 个元件，但**是最容易接错的一页**。画完单独盯一遍：分压比是不是 6.10、NTC 是不是在下边。

### Sheet 3 输出与交互

三组独立小电路，互不相干，可以分开画：

**A. 电机驱动（M1）**

| 检查项 | 正确做法 |
|---|---|
| VM 去耦 | C2（100 µF）与 0.1 µF 紧贴 M1 的 VM / GND |
| VM 来源 | `VBAT_F` 直供，不经过 Buck |
| 电机端 | D2（TVS）跨接 J2 两端 |
| 逻辑供电 | M1 的 VCC 接 `+3V3`（不是 5 V） |

**B. 蜂鸣器（Q1 + BUZ1）**

```
PB0 ── R6(1k) ── Q1(B)      Q1(E) → GND
                            Q1(C) → BUZ1(−)
+5V ──────────────────────── BUZ1(+)
```
- 有源蜂鸣器直接把 `+5V` 接到 BUZ1 正极
- **必须加续流二极管**（并在 BUZ1 两端，阴极朝 `+5V`），否则三极管关断瞬间的反电动势会打穿它
- 若用无源蜂鸣器，则改由 PWM 驱动，接法不同——买之前确认是"有源"

**C. LED 与按键**

| 检查项 | 正确做法 |
|---|---|
| LED | `+3V3` → R5(1k) → LED 阳极 → 阴极 → GND（或反过来接 PB1 灌电流） |
| 按键 | `+3V3` → R4(10k) → PC13；PC13 经 SW1 到 GND；PC13 对地并 100 nF |
| 去抖电容 | 与 SW1 并联，不要串在信号线上 |

### Sheet 4 主控与接口

**画法顺序**：先放 U1 排母 → 按"上电顺序"给引脚标网络（电源→地→模拟→控制→通信）→ 再逐个接 J3/J4/J5/J6

| 检查项 | 正确做法 |
|---|---|
| 排母引脚顺序 | **必须拿实物核心板逐脚核对**，不同厂家的 C8T6 核心板丝印方向不一致 |
| 5V 与 3V3 | 5V 引脚接 `+5V`（进板载 LDO），3V3 引脚是**输出**，接 `+3V3` |
| 未用引脚 | 全部留空，不要图省事并到 GND |
| J6 定义 | 1=`+3V3_WIFI` 2=`GND` 3=`USART3_TX` 4=`USART3_RX` 5=`WIFI_EN` 6=`WIFI_IO0` |
| SWD | J4 只接 3V3 / SWDIO / SWCLK / GND，不要接 5V |

## 四、立创EDA 操作要点

1. **新建工程**，先建 4 张图（右键工程 → 新建图页），命名 `1_Power` `2_Analog` `3_Output` `4_MCU`
2. **器件优先从"标准库"搜**，带商城编号的直接用；模块类（Buck、TB6612、核心板）用"排母"代替，不要自己画符号
3. **网络标签从第一笔就用**：`放置 → 网络标签`，快捷键 `N`；不要靠拉线跨越图页
4. 电源符号统一用 `+5V` `+3V3` `GND` 三种，`GND` 必须用同一个符号
5. 每画完一页跑一次 **设计 → 检查 DRC/ERC**，别攒到最后
6. 全部画完 → **设计管理器**确认没有"未连接引脚"和"单网络"

---

## 五、ERC 前的 8 条必查

- [ ] 每个器件都有封装（没有封装的会在转 PCB 时消失）
- [ ] 电源网络没有短路（`+5V` 与 `+3V3` 之间无直连）
- [ ] 所有 GND 用的是同一个符号
- [ ] 没有悬空的使能脚（U3 的 EN、TB6612 的 STBY）
- [ ] 二极管、电解电容、LED 极性方向
- [ ] 排母引脚顺序与实物核对过
- [ ] 网络名拼写一致（`+3V3` 与 `3V3` 是两个网络，这种错最难查）
- [ ] 4 张图之间的跨页网络，在两端都能找到同名标签

## 六、三个会导致重画的坑

**1. 核心板排母顺序凭印象画**
不同批次的核心板，丝印方向和引脚排列可能不同。**拿着板子，一个脚一个脚对**，把结果先记在纸上再画。这一条错了，整块板报废。

**2. TB6612 模块当成芯片画**
模块的引脚是排针（VCC/GND/VM/AIN1/AIN2/PWMA/STBY/…），不是芯片的 SSOP-24。搜"2×8P 排母"当载体，按模块丝印标网络。

**3. `+3V3` 和 `+3V3_WIFI` 混成一个网络**
看起来都是 3.3 V，但一个是核心板 LDO 出来的、一个是 U3 出来的。合成一个网络，等于把 WiFi 的电流尖峰直接灌进 MCU 的电源。**这是整块板最隐蔽的错**，ERC 不会报。
