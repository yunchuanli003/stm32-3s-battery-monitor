## 一、分页方案（4 页）

按功能分页，每页只做一件事。页数不是越多越好，4 页是这块板的甜点区。

| 页 | 名称 | 放什么（位号） |
|---|---|---|
| Sheet 1 | 电源与保护 | J1、F1、D1、C1、M2（K7805 降压模块，3 脚直插）、C3、U3、C4~C10、C12、C13 |
| Sheet 2 | 模拟采样 | R1、R2、R3、J7、C11、C14 |
| Sheet 3 | 输出与交互 | M1（TB6612 座）、C2、D2、J2、R5、LED1、R6、Q1、BUZ1、R4、SW1、C15 |
| Sheet 4 | 主控与接口 | U1、U2（两个 1×20P 排母拼成 40 脚）、J3（OLED）、J5（串口）、J6（WiFi） |

> 四页合计 16 + 6 + 12 + 5 = **39 个元件**，与 BOM 完全一致（J4 SWD 口已于 2026-10-23 删除，见 v1.6 修订记录）。

**为什么把主控放最后**：U1 + U2 合计 40 个引脚，先画它等于面对一堵墙；把电源、模拟、输出画完，网络名都定好了，最后画主控就是把已有网络"对号入座"，不容易漏。

## 二、全局网络命名（画之前先定死）

网络名一旦定好，四条 Sheet 之间靠它连接，不用拉长线。**全部大写，带下划线**。

| 网络名 | 含义 | 出现在 |
|---|---|---|
| `VBAT` | 电池正极（保险丝前） | Sheet1 |
| `VBAT_FUSE` | 保险丝之后、D1 阳极之前，只有这一段 | Sheet1 |
| `VBAT_F` | **全板主母线**：D1 阴极之后（Buck、TB6612 VM、电解、分压上臂都从这取） | Sheet1、Sheet2、Sheet3 |
| `GND` | 公共地 | 全部 |
| `+5V` | Buck 输出 | Sheet1、Sheet2、Sheet3、Sheet4 |
| `+3V3` | 核心板 3.3 V 输出（模拟、数字、TB6612 逻辑电源） | Sheet2、Sheet3、Sheet4 |
| `+3V3_WIFI` | U3 独立输出，只给 J6 | Sheet1、Sheet4 |
| `PA4` / `PA5` | ADC 输入（原 PA0/PA1，已因板载冲突改） | Sheet2→Sheet4 |
| `PB12` / `PB13` / `PA6` / `PB14` | 电机控制（原 PA2/PA3/PA8） | Sheet3→Sheet4 |
| `AO1` / `AO2` | TB6612 输出 → 电机端子 | Sheet3 |
| `PB0` / `PB1` | 蜂鸣器 / LED | Sheet3→Sheet4 |
| `PB6` / `PB7` | I2C | Sheet4、J3 |
| `PA9` / `PA10` | USART1 | Sheet4、J5 |
| `USART3_TX` / `USART3_RX` | PB10 / PB11 | Sheet4、J6 |
| `WIFI_EN` / `WIFI_IO0` | 模块使能与烧录选择 | Sheet4 |
| `PC13` | 按键 | Sheet3→Sheet4 |

**命名两条规矩**：

1. 电源网络用 `+5V` `+3V3` 这种带正号的形式，GND 单独一种符号，不要出现 `VCC`、`VDD`、`5V` 混用
2. 信号名跟 MCU 引脚名对齐（`PA4` 而不是 `ADC1_IN0`），调试时一眼能对上数据手册

## 三、逐页画法与自检点

### Sheet 1 电源与保护

**画法顺序**：J1 → F1 → D1 → 分两路（Buck / TB6612 VM）→ 补 C1、C3 → 加 U3 及其电容

| 检查项 | 正确做法 | 常见错法 |
|---|---|---|
| 保险丝位置 | 在 D1 **之前**，紧贴 J1 | 放到 D1 之后，短路时保护不了反接二极管 |
| D1 方向 | 阳极接保险丝输出，阴极出 `VBAT_F` 母线，**全板（含 TB6612 VM 与两颗电解）都从阴极取电** | 反了整板不上电 |
| C1 位置 | Buck 输入端，靠近模块 Vin | 画在 D1 之前，起不到抑制输入纹波的作用 |
| U3 输入 | 从 `+5V` 取电 | 从 `VBAT_F` 取电 → 压差 9 V，白烧 0.6 W |
| U3 输出 | `+3V3_WIFI` 独立命名 | 与 `+3V3` 混成一个网络 → WiFi 发射时拉垮 MCU |

**这页画完**：ERC 应无错，`VBAT_F`、`+5V`、`+3V3_WIFI` 三个网络各有明确的源。

### Sheet 2 模拟采样

**画法顺序**：R1 → R2 → 加 C11 → 引 `PA4` → R3 → J7 → 加 C14 → 引 `PA5`

| 检查项 | 正确做法 |
|---|---|
| NTC 位置 | **下臂**（J7-2 → GND，J7-1 → `PA5`，R3 上拉到 +3V3），与现有固件公式方向一致 |
| 电容位置 | C11 / C14 并联在下臂电阻两端，即"采样点对地" |
| 采样点来源 | `PA4` `PA5` 直接从两个电阻中间引出，不要从电容另一端引 |
| 封装 | R1/R2/R3 用 0805；J7 是直插螺钉端子，与 J1/J2 同封装 `CONN-TH_XY301V-A-5.0-2P` |
| 端子脚序 | **J7-1 = `PA5`（上）、J7-2 = `GND`（下）**。J7 两脚间距 2.54 mm，与原 RN1 符号 10.16 mm 跨度不一致，两根导线要各加一段短跳线落到引脚上 |

> 这一页只有 6 个元件（R1、R2、R3、C11、C14、J7），但**是最容易接错的一页**。画完单独盯一遍：分压比是不是 6.10、NTC 是不是在下边、J7 两脚有没有接反。

### Sheet 3 输出与交互

三组独立小电路，互不相干，可以分开画：

**A. 电机驱动（M1）**

| 检查项 | 正确做法 |
|---|---|
| VM 去耦 | C2（100 µF）与 0.1 µF 紧贴 M1 的 VM / GND |
| VM 来源 | `VBAT_F` 直供，不经过 Buck |
| 电机端 | D2（TVS）跨接 J2 两端 |
| 逻辑供电 | M1 的 VCC 接 `+3V3`（不是 5 V） |

**B. 蜂鸣器（Q1 + BUZ1）**

```
PB0 ── R6(1k) ── Q1(B)      Q1(E) → GND
                            Q1(C) → BUZ1(−)
+5V ──────────────────────── BUZ1(+)
```
- 已锁定 **HYE1206-05ST（C17701079）**：库描述明确「驱动方式：有源（内含驱动线路），额定电压 5 V，频率 2.6 kHz」，与 `+5V` 供电直接匹配
- 有源蜂鸣器直接把 `+5V` 接到 BUZ1 正极，固件**拉高 PB0 即响**，不需要 PWM
- **续流二极管未加**（图上无此件）：有源蜂鸣器内含驱动线路，Q1 切换的是模块输入端而非裸线圈，反电动势风险显著低于无源电磁式。若日后实测有干扰，再补一颗 1N4148（阴极朝 `+5V`、阳极接 BUZ1−）
- 若换回无源蜂鸣器，则必须改由 PWM 驱动并补续流二极管——**本设计不用无源**

**C. LED 与按键**

| 检查项 | 正确做法 |
|---|---|
| LED | `+3V3` → R5(1k) → LED 阳极 → 阴极 → GND（或反过来接 PB1 灌电流） |
| 按键 | `+3V3` → R4(10k) → PC13；PC13 经 SW1 到 GND；PC13 对地并 100 nF |
| 去抖电容 | 与 SW1 并联，不要串在信号线上 |

### Sheet 4 主控与接口

**画法顺序**：先放 U1、U2 两个排母 → 按"上电顺序"给引脚标网络（电源→地→模拟→控制→通信）→ 再逐个接 J3/J5/J6

| 检查项 | 正确做法 |
|---|---|
| 排母引脚顺序 | **必须拿实物核心板逐脚核对**，不同厂家的 C8T6 核心板丝印方向不一致 |
| 5V 与 3V3 | 5V 引脚接 `+5V`（进板载 LDO），3V3 引脚是**输出**，接 `+3V3` |
| 未用引脚 | 全部留空，不要图省事并到 GND |
| J6 定义 | 1=`+3V3_WIFI` 2=`GND` 3=`USART3_TX` 4=`USART3_RX` 5=`WIFI_EN` 6=`WIFI_IO0` |

> **本页不放 SWD 接口**。野火核心板 40 针排母未引出 PA13/PA14，板上再放 SWD 排针也接不到 MCU，属无效接口（原 J4 已于 2026-10-23 删除）。调试与烧录走核心板自带调试排针和 Type-C。

## 四、立创EDA 操作要点

1. **新建工程**，先建 4 张图（右键工程 → 新建图页），命名 `1_Power` `2_Analog` `3_Output` `4_MCU`
2. **器件优先从"标准库"搜**，带商城编号的直接用；**插座类**（TB6612 模块座、核心板 1×20P 排母）用"排母"代替，不要自己画符号。**M2 例外**：K7805-1000R3 是 3 脚直插器件，直接搜料号 `C111280` 用官方符号 + SIP-3 封装，**不留排母**（3 脚立式插排母会晃）
3. **网络标签从第一笔就用**：`放置 → 网络标签`，快捷键 `N`；不要靠拉线跨越图页
4. 电源符号统一用 `+5V` `+3V3` `GND` 三种，`GND` 必须用同一个符号
5. 每画完一页跑一次 **设计 → 检查 DRC/ERC**，别攒到最后
6. 全部画完 → **设计管理器**确认没有"未连接引脚"和"单网络"

## 五、ERC 前的 8 条必查

- [ ] 每个器件都有封装（没有封装的会在转 PCB 时消失）
- [ ] 电源网络没有短路（`+5V` 与 `+3V3` 之间无直连）
- [ ] 所有 GND 用的是同一个符号
- [ ] 没有悬空的使能脚（U3 的 EN、TB6612 的 STBY）
- [ ] 二极管、电解电容、LED 极性方向
- [ ] 排母引脚顺序与实物核对过
- [ ] 网络名拼写一致（`+3V3` 与 `3V3` 是两个网络，这种错最难查）
- [ ] 4 张图之间的跨页网络，在两端都能找到同名标签

## 六、三个会导致重画的坑

**1. 核心板排母顺序凭印象画**
不同批次的核心板，丝印方向和引脚排列可能不同。**拿着板子，一个脚一个脚对**，把结果先记在纸上再画。这一条错了，整块板报废。

**2. TB6612 模块当成芯片画**
模块的引脚是排针（VCC/GND/VM/AIN1/AIN2/PWMA/STBY/…），不是芯片的 SSOP-24。搜"2×8P 排母"当载体，按模块丝印标网络。

**3. `+3V3` 和 `+3V3_WIFI` 混成一个网络**
看起来都是 3.3 V，但一个是核心板 LDO 出来的、一个是 U3 出来的。合成一个网络，等于把 WiFi 的电流尖峰直接灌进 MCU 的电源。**这是整块板最隐蔽的错**，ERC 不会报。
