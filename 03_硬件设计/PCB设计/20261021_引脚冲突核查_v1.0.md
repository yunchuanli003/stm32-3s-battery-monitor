## 一、结论

**PA0 / PA1 / PA2 / PA3 这四个脚在核心板上已经接了板载器件，不能按当前方案用于 ADC 采样和电机控制。**

如果照现在的引脚表打板，会出现：

| 引脚 | 当前方案用途 | 板载实际连接 | 后果 |
|---|---|---|---|
| PA0 | ADC 电池电压 | **KEY1 按键** | 按键另一端接地，按下瞬间把分压点短路到 GND，读数掉到 0；不按时按键电路也并进分压网络 |
| PA1 | ADC NTC 温度 | **LED_R（红色 LED）** | LED 是非线性负载，ADC 输入端被钳位/分流，温度读数系统性偏低 |
| PA2 | TB6612 AIN1 | **LED_G（绿色 LED）** | 电机正转时绿灯跟着亮，信号被 LED 分走电流 |
| PA3 | TB6612 AIN2 | **LED_B（蓝色 LED）** | 电机反转时蓝灯跟着亮 |

## 二、证据

**证据 1：官方引脚分配表原文（"连接说明"列）**

```
引脚名称 | 连接说明   | 默认功能
PA0     | KEY1      | GPIO
PA1     | LED_R     | GPIO
PA2     | LED_G     | GPIO
PA3     | LED_B     | GPIO
PC13    | KEY2      | GPIO
```

**证据 2：原理图第 3 页（电源页）**

该页同时出现 `PA1 PA2 PA3` 与 `LED1 RED / LED3 BLUE / R4 1K / R2 1K / L2 330R`，即 PA1~PA3 经限流电阻接到板载 RGB 灯。

**证据 3：实物照片**

`05_交付产物/演示素材/项目2.0实物图.jpg` 中，右侧黑色核心板上 RGB 灯呈绿/红/蓝同时点亮状态。
这三颗灯分别挂在 PA1/PA2/PA3 上——**灯亮，说明这三个脚正在被驱动**，与电机控制信号一致。

## 三、今天就能做的 3 分钟验证

不用改任何东西，面包板上直接验：

**验证 A（最快，一眼可见）**
让电机正转 → 看核心板上的 RGB 灯是否变绿；反转 → 是否变蓝；停 → 是否熄灭。
若灯随电机变化，PA2/PA3 被 LED 占用即成立。

**验证 B**
按住核心板上的 **KEY1** 不要松，同时看串口打印的 `Battery:` 值。
若电压读数明显掉下来（甚至到 0），PA0 接 KEY1 即成立。

**验证 C**
万用表直流电压档，黑笔接 GND、红笔点 PA1 排针，读数应该接近分压计算值（约 1.65 V）。
再按住 KEY1 观察 PA0 是否被拉低。

三条里任意一条成立，就按第四节的方案改。

## 四、修订后的引脚分配（推荐）

### 4.1 原则

1. 只用引脚表中"连接说明"为空、或明确标注可通过跳线断开的脚
2. ADC 只能用 `ADC12_INx` 且未被占用的脚：**PA4 / PA5 / PA6 / PA7 / PB0 / PB1**
3. 板载已提供的资源直接用：PC13 有 KEY2，省一个外接按键

### 4.2 新分配表

| 功能 | 原引脚 | **新引脚** | 备注 |
|---|---|---|---|
| ADC 电池电压 | PA0 | **PA4**（ADC12_IN4） | 分压电路不变，只改接入脚 |
| ADC NTC 温度 | PA1 | **PA5**（ADC12_IN5） | 同上 |
| 电机 PWM | PA6 | **PA6**（TIM3_CH1） | 不变，PA6 空闲 |
| TB6612 AIN1 | PA2 | **PB12** | 空闲 |
| TB6612 AIN2 | PA3 | **PB13** | 空闲 |
| TB6612 STBY | PA8 | **PB14** | 空闲 |
| 蜂鸣器 | PB0 | **PB0** | 不变 |
| LED 指示 | PB1 | **PB1** | 不变 |
| OLED I2C | PB6/PB7 | **PB6/PB7** | 不变 |
| 调试串口 | PA9/PA10 | **PA9/PA10** | 不变（跳线帽接 CH340，可保留） |
| WiFi USART3 | PB10/PB11 | **PB10/PB11** | 不变 |
| 按键 | PC13（外接） | **PC13（用板载 KEY2）** | 省掉外接按键 SW1 与上拉电阻 |
| SWD | PA13/PA14 | **PA13/PA14** | 不变，板载已有 |

### 4.3 为什么不选"拆板载元件"

PA1~PA3 的限流电阻是 0402 封装，拆掉需要热风枪，且不可逆；而改引脚只是改固件配置 + 改 PCB 网络名，成本低得多。

### 4.4 连带改动

**固件（CubeMX）**
- ADC1 通道从 `CH0/CH1` 改为 `CH4/CH5`（PA4/PA5），扫描顺序与 DMA 缓冲区含义不变
- AIN1/AIN2/STBY 改到 PB12/PB13/PB14，对应 GPIO 初始化重配
- 中断/定时器配置不变

**PCB（原理图）**
- Sheet 2 模拟采样：`PA0`→`PA4`、`PA1`→`PA5`（网络名跟着改）
- Sheet 3 输出：`PA2`→`PB12`、`PA3`→`PB13`、`PA8`→`PB14`
- Sheet 3 按键：**删除 SW1、R4 及去抖电容**，PC13 直接用板载 KEY2
- 网络命名表同步更新

**元件数量变化**：少一个按键、一个上拉电阻、一个 100 nF。

## 五、对现有面包板样机的影响

现在样机能跑，是因为：

- KEY1 平时不按，分压回路只是被它并联了一点点（已被 `divider_k = 6.21` 的实测标定吸收掉）
- LED 只在引脚输出高电平时点亮，做 ADC 输入时（1.65 V 左右）红 LED 未导通，影响较小

**但这属于"碰巧能用"，不是"设计正确"。** 一旦：
- 有人按了 KEY1 → 电压读数瞬间掉到 0，报警误触发
- 温度升到触发风扇 → PA2/PA3 输出高 → 灯亮，ADC 旁边的引脚来回翻转，采样噪声变大

打板前把引脚改对，比打完板发现再飞线划算得多。
