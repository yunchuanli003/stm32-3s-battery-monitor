## 二、四条硬指标（不达标就别下单）

| 看什么 | 要什么 | 不达标会怎样 |
|---|---|---|
| 主控 | ESP8266，板载 ESP-12E/F，**4 MB Flash** | 1 MB 是老版 V2，刷完固件空间紧张 |
| 串口芯片 | CH340 / CH340C / CH343 | 标 CP2102 的也能用，驱动不同 |
| USB 口 | **Type-C 优先**，Micro-USB 次之 | Micro 座焊盘小，斜插容易连根拔起 |
| 单价 | 12–22 元 | 低于 10 元大概率是拆机板或翻新板 |

卖家页面上最好能看到**实物照片**（不是渲染图）、有**销量和真实评价**、明确写了 Flash 大小。

## 三、三个必踩的坑（按概率排序）

### 坑 1：附送的数据线是纯充电线

新手第一大坑。插上后设备管理器毫无反应，会误以为板子坏了。

- Type-C 版：直接用自己的手机数据线，绕开这个问题
- Micro-USB 版：下单前问清是不是数据线，或者干脆自备

**排查顺序永远是：先换线，再装驱动。**

### 坑 2：CH340 驱动装不上

Win11 的「内存完整性 / 内核隔离」会拦掉旧版 CH340 驱动，表现为驱动装了但设备带黄色感叹号。

- 去 WCH 官网 `wch.cn` 下 `CH341SER.EXE` 最新版
- 别用第三方下载站的版本
- 装完拔插一次板子，才会出现 COM 口

### 坑 3：买错型号

三个名字看着像，实际完全不是一回事：

| 名称 | 是什么 | 能不能用 |
|---|---|---|
| **ESP8266 ESP-01S** | 8 针小模组，**没有 USB** | 单独买回来插不上电脑，用不了 |
| **NodeMCU V3** | 30 针开发板，带 USB、带 LDO、带自动下载电路 | **要买的就是这个** |
| **ESP32** | 另一颗芯片，引脚和现有资料全对不上 | 别因为「性能更强」换方案 |

## 四、到货验货（5 分钟，三步）

按顺序做，任何一步不过就停下来查，**不要往下走到 STM32 联调**。

### 步骤 1：认串口

插 USB → 打开设备管理器 → 端口（COM 和 LPT）

- 出现 `USB-SERIAL CH340 (COMx)` → **通过**
- 出现带黄色感叹号的未知设备 → 驱动问题，看坑 2
- 什么都不出现 → 先换线，再看是不是 USB 口供电不足（换主机后置口）

### 步骤 2：确认芯片活着

串口助手打开刚认到的 COM 口，波特率 **115200**，按一下板子上的 **RST**。

- 刷出一串乱码或启动信息 → **通过**（ESP8266 启动日志波特率不一定是 115200，乱码是正常的，说明有数据在往外吐）
- 完全没反应 → 试 74880 波特率；仍无输出则模块可能有问题

### 步骤 3：确认能进下载模式

按住 **FLASH** 不放 → 按一下 **RST** → 松开 FLASH。

配合 `esptool.py` 或 Arduino IDE 能看到芯片信息（Flash 大小、MAC）→ **通过**，这块板可以刷固件了。

> 把三步的结果和 COM 口号记下来，后面配 Arduino IDE / 写固件都要用。

## 六、到货之后的顺序（先看，不用现在做）

1. 单独给 NodeMCU 通电，串口能打印 → 确认模块本身没问题
2. 刷一个最小固件（串口透传），确认能收发
3. 与 STM32 联调：NodeMCU TX → PB11，NodeMCU RX ← PB10，**GND 必须共地**
4. 波特率两边都设 115200，先跑通「STM32 发一行，电脑上看到一行」
5. 再接 WiFi、再谈 JSON 数据帧、再谈 MQTT

**供电红线：NodeMCU 只用 USB 供电。** 不要从 STM32 板子的 3V3 引线过去——WiFi 发射峰值 300 mA，板载 LDO 撑不住，现象是「一连 WiFi 就重启」，极易误判成程序 bug。

## 七、接线对照（画在纸上贴桌上）

```
NodeMCU                     STM32 板 J6
────────                    ────────────
GND      ────────────────   GND      (J6-2)
D10/TX   ────────────────   PB11     (J6-4, USART3_RX)
D9/RX    ────────────────   PB10     (J6-3, USART3_TX)
（不接）                    +3V3_WIFI (J6-1)   ← 开发阶段悬空
（不接）                    WIFI_EN   (J6-5)
（不接）                    WIFI_IO0  (J6-6)
```

J6-1 的 `+3V3_WIFI` 那根**不要接**：NodeMCU 有自己的 USB 供电和 LDO，两边同时往同一根 3.3 V 上灌电会打架。
