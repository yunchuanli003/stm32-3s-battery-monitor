# 按键控制功能测试用例

## 测试目标

验证 KEY2 单键控制功能（长按停止、短按开启）是否正常工作，特别是修复"第二次长按不打印信息"的问题。

---

## 测试环境

| 项目 | 配置 |
|------|------|
| **MCU** | STM32F103C8T6 |
| **按键** | KEY2 (PC13) |
| **串口** | USART1, 115200, 8N1 |
| **系统时钟** | 72MHz |
| **串口调试助手** | 野火多功能调试助手 |

---

## 测试前准备

1. ✅ 烧录最新的固件到开发板
2. ✅ 打开串口调试助手，波特率 115200
3. ✅ 按复位键，确认能看到开机欢迎信息
4. ✅ 确认能看到电压数据正常打印

## 问题排查指南

如果测试不通过，按以下步骤排查：

### 现象 A：第二次长按不打印信息

1. 确认 TC-002 是否通过（停止后长按不触发短按）
2. 如果 TC-002 不通过，检查 `key2_long_triggered` 是否在 system_running == 0 时也被设置

### 现象 B：短按时出现延迟的停止信息

1. 这是之前 bug 的典型现象
2. 确认代码中 `key2_long_triggered = 1` 是否在 `if(system_running == 1)` 外面

### 现象 C：长按时间不对

1. 检查 `key2_long_press_cnt < 60` 的判断
2. 60 * 50ms = 3秒，确认主循环延时是 50ms
